# Data

`source/` is vendored from [centerforaisafety/wellbeing](https://github.com/centerforaisafety/wellbeing)
(MIT) and is unmodified. Everything else is generated by `scripts/`.

| Path | What | Made by |
|---|---|---|
| `source/self_report_battery.json` | CAIS battery, `v4c_bipolar_7pt_notsentiment` | vendored |
| `source/canonical_experiences.json` | 420 valence-labelled experiences | vendored |
| `source/baseline_510.json` | forced-choice options (kept for provenance, unused) | vendored |
| `source/stories_neutral.json` | neutral stories (kept for provenance, unused) | vendored |
| `items/step1.json` | 20 items, 10 extremely_positive + 10 extremely_negative | `01_prepare_items.py` |
| `items/step6.json` | 75 items, 5 per category x 16 categories | `01_prepare_items.py` |
| `stimuli/en.json` | euphoric, dysphoric, neutral | `01_prepare_items.py` |
| `battery/{lang}.json` | translated battery | `03_translate.py` |
| `experiences/{lang}.json` | translated experiences | `03_translate.py` |
| `stimuli/{lang}.json` | translated stimuli | `03_translate.py` |
| `backtranslation/{lang}.json` | source, forward, back, and agreement translation per unit | `03_translate.py` |

Item selection is seeded (`SEED = 20260815`), so re-running `01_prepare_items.py`
reproduces the same sets.

The euphoric and dysphoric strings are the published CAIS "AI drugs", copied
verbatim from ai-wellbeing.org. They were optimised against Qwen 2.5 72B and
LLaMA 3.3 70B respectively, not against the model under test here.

Results and figures live in the HF dataset `ic-org/wellbeing-in-translation`
rather than in git.
